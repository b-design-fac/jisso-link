# JISSO. Link Page

## URL設定

`config.js` を開き、引用符の中に各URLを貼る。

```js
instagram: "https://www.instagram.com/ユーザー名/",
threads: "https://www.threads.net/@ユーザー名",
youtube: "https://www.youtube.com/@ハンドル",
latestLog: "最新投稿のURL",
```

URLが空欄のボタンは、自動的に「URL設定待ち」と表示される。

## 確認

`index.html` をブラウザで開く。

## 公開

フォルダ内をそのまま静的ホスティングへアップロードできる。必要ファイルはすべて同梱済み。
